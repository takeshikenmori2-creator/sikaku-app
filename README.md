# 海事代理士 筆記試験 演習アプリ

ランダムに4択問題を出し続けるだけの、個人学習用の静的アプリ。
`index.html` をブラウザで開けば動く（ビルド・サーバ不要）。

## 使い方

```
git clone <このリポジトリ>
cd sikaku-app
open index.html        # Linux なら xdg-open index.html
```

- 選択肢をクリック、またはキーの `1`〜`4` で解答
- 同じ条文に空欄が複数ある問題は1問にまとまっている。すべての空欄を選んでから「採点する」（`Enter`）
- 正誤問題の選択肢は `○` と `×`
- 解答後は `Enter` または `Space` で次の問題へ
- ヘッダーに **正解数 / 出題数** と正答率を常時表示。連続正解が2以上になると連続数も出る
- スコアは**ページを開くたびにゼロから**。途中でリセットしたければヘッダーの「リセット」
- 「範囲」で科目を絞れる。1〜4時限目／20点科目のプリセット、過去問だけ／条文ベースだけの切り替えあり（選択内容だけは次回も引き継ぐ）
- 各問に出典（令和X年 科目 大問N）と解説、重要度★1〜3が付く
- ★は過去5年で同じ論点が何年分に出ているか（3年以上→★3／2年→★2／1年のみ→★1）。「範囲」から★2以上・★3のみに絞れる
- 間違えた問題は約1/3の確率でその場のセッション中に再出題される（範囲パネルでオフにできる）
- 選択肢の並び順は毎回シャッフルされる（同じくオフにできる）

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` / `assets/` | アプリ本体。外部依存ゼロ |
| `data/subjects.json` | 筆記20科目の定義（配点・時限） |
| `data/src/*.json` | 科目ごとの問題ソース。**編集するのはここ** |
| `data/questions.js` / `.json` | `tools/build.py` が生成する配信用バンドル。直接編集しない |
| `data/overlay/*.json` | 機械変換した過去問への加筆（誤答・解説）。項目idごとの上書き |
| `exam_pdf/*.pdf` | 国土交通省公開の筆記試験問題・模範解答（令和3〜7年） |
| `data/exam/` | PDFから抽出した中間データ（解答・問題バンク・積み残し） |
| `tools/build.py` | `data/src/` をまとめて検証・生成する |
| `tools/extract_pdf.py` | 設問PDFを構造化テキストに変換する |
| `tools/parse_answers.py` | 模範解答PDFを解答の辞書に変換する |
| `tools/build_exam_bank.py` | 設問と解答を突き合わせて選択式に組み立てる |
| `tools/exam_to_src.py` | 過去問バンクと overlay を合成して問題ソースを生成する |
| `tools/rank_importance.py` | 過去5年の出題頻度から重要度★を算出する |
| `tools/build_artifact.py` | CSS・JS・問題データを1枚のHTMLにまとめる |
| `tools/fetch_official_pdfs.py` | 国交省サイトから過去問PDFを収集する |

問題を足したら必ず:

```
python3 tools/exam_to_src.py      # 過去問側を編集したとき
python3 tools/build.py
python3 tools/rank_importance.py  # 重要度を計算し直す
python3 tools/build.py            # 重要度を取り込んで再ビルド
```

id重複・選択肢の重複・answerの範囲外などはビルドが弾く。

## 問題の出どころ

### 公式過去問（800問）

`exam_pdf/` に国土交通省が公開している令和3〜7年の筆記試験問題と模範解答の
PDFを置いてある。配布元は国土交通省「海事代理士になるには」
<https://www.mlit.go.jp/about/file000049.html>。

これを次の流れで選択式に変換している。

```
exam_pdf/*.pdf
  ├─ tools/extract_pdf.py    設問PDF → 構造化テキスト（解答欄の枠を【】として復元）
  ├─ tools/parse_answers.py  模範解答PDF → {年/科目/大問-枝番: 解答}
  ├─ tools/build_exam_bank.py  両者を突き合わせて枝問単位の問題に分解
  └─ tools/exam_to_src.py    data/overlay/ の加筆を合成して data/src/kako/ を生成
```

同じ大問の空欄はひとまとめにして、1問で全部の空欄を答える形にしている
（本試験の出題単位に揃えるため）。正誤の組合せ問題と○×問題だけは1文ずつの
独立した問題にしてある。

変換の要点:

- 解答欄の枠はPDF上では文字ではなく罫線なので、描画された矩形の位置から復元する
- 模範解答の大問→枝番の構造を手がかりに設問本文の切り出し位置を決める
- **正誤の組合せ問題**は①②を独立した○×問題に分解する
- **語群から選ぶ穴埋め**は語群の他の語をそのまま誤答に使う（本試験の誤答がそのまま使える）
- **自由記入の穴埋め**は誤答を機械で作れないので、`data/overlay/` に手で書いた誤答3つを合成する

模範解答PDFのうち2ページは文字がアウトライン化されていてテキスト抽出できないため、
画像に起こして読み取った内容を `data/exam/answers_manual.json` に手入力してある。

機械変換で正しく切り出せなかった枝問（どの空欄が問われているか本文から特定できないもの等）は
`data/exam/skipped.json` に理由付きで書き出され、収録されない。

### 条文ベースの自作問題（294問）

過去問だけでは手薄になる論点を補うため、各法令の条文・制度から作成した4択問題。
アプリ上は「条文ベース」のバッジが付き、「範囲」から過去問だけに絞ることもできる。

条文の内容は正確を期しているが、一次資料は必ず
[e-Gov法令検索](https://laws.e-gov.go.jp/) で確認すること。

### 別の年度を足す

```
python3 tools/fetch_official_pdfs.py --list     # 配布元から何が取れるか見る
python3 tools/fetch_official_pdfs.py --years 7  # PDFを downloads/ へ
```

落としたPDFを `exam_pdf/` に置き、上記4つのツールを順に実行する。

## 問題データの形式

`data/src/<科目id>.json`:

```json
{
  "subject": "senpakuhou",
  "questions": [
    {
      "id": "001",
      "q": "設問文",
      "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
      "answer": 2,
      "explain": "解説。選択肢の番号では参照しないこと（出題時にシャッフルされるため）",
      "ref": "船舶法1条"
    }
  ]
}
```

`answer` は0始まりの添字。最終的な問題idは `<subject>-<id>`。

## 試験の概要（参考）

- 筆記試験20科目・240点満点。配点20点が4科目、10点が16科目
- 合格基準は総得点の60%以上（受験者の平均正答率が60%を上回る場合はその平均以上）
- 口述試験は船舶法・船舶安全法・船員法・船舶職員及び小型船舶操縦者法の4科目

## ライセンス

個人学習用。

## Webアプリとして使う

`tools/build_artifact.py` がCSS・JS・問題データを1枚のHTMLに埋め込んだ
`artifact/kaiji-drill.html` を生成する。これをそのままどこかに置けばWebアプリになる
（依存なし、サーバ不要）。

```
python3 tools/build_artifact.py
```
